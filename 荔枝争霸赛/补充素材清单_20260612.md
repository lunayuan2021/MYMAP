# 《一骑红尘：荔枝争运战》补充素材清单

版本：2026-06-12
用途：回放引擎视觉/听觉升级所需的**额外**素材（已有的 15 站点建筑、马车、船、角色、冰鉴箱等不在此列）。
优先级：**P0 = 直接影响验收/观感，必做；P1 = 强烈建议；P2 = 锦上添花。**

> ⚙️ 重要约定：本清单的文件名和投放路径与代码实现一一对应。
> 素材做好后**按下面写的文件名**放进对应文件夹，引擎会自动检测并使用；没放的项目走程序化兜底（不会报错）。
> `StreamingAssets/` 指 Unity 工程的 `Assets/StreamingAssets/`，打包后对应 `游戏名.app/Contents/Resources/Data/StreamingAssets/`（比赛 reply.txt 也放这里）。

### 角色动画（进阶，P1→P2）

现有 队长/队员/分队队员 GLB 若无骨骼，需要补**绑定骨骼版本**并附带动画片段（可用 Mixamo 通用骨骼）：
`walk`（行走循环）、`run`（奔跑循环）、`row`（划船循环）、`build`（搭建/加固，用于设卡与增援）、`attack`（劈砍，用于攻坚与清障）、`cheer`（欢呼，交付/胜利用）。
命名建议：`captain_rig.glb`、`member_rig.glb`（动画打进同一文件）。没有它们引擎仍可运行（角色保持滑行+浮动），有了之后观感跨档。

## 六、制作优先顺序建议（给你排期用）

1. **第一批（P0，决定演示效果下限）**：`main_cn.ttf` 字体 → 4 张卡牌立绘 → `panel_frame.png`/`task_scroll.png`/`settlement_bg.png` → 3 个天气图标 → `guard_barricade.glb` → `bgm_normal/bgm_rush` + 6 个 P0 音效。
2. **第二批（P1）**：资源/任务图标、横幅类、环境音与循环音、旗杆与告示牌模型、开场视频。
3. **第三批（P2 + 进阶）**：角色绑骨+动画、其余装饰，以及**存量站点模型减面**（强烈建议：目标单站点 ≤10 万面，否则加特效后帧率压力大）。
