## WebGL 旁注
- WebGL 包"加载失败/Your Browser does not support WebGL"＝用 file:// 直接开了，必须经 HTTP（包内自带 `start.sh`）。
- 同事在"黄区"打开报 `jx.event.js / site.main.js / Jx.$package` 的错 = **黄区门户网页自己的 JS 框架(Jx/MooTools)崩了，不是我们的 Unity 包**（Unity 用自己的加载器，从不用 Jx）。让对方用纯静态 HTTP 直开我们的 index.html，或找门户维护方修。
- 昨日(6-24)的 WebGL 包不含今天所有修复；要新包需重新构建（原生包才是性能最优解）。

## 重要操作经验（避免重蹈覆辙）
- **改完生成器/任何编辑器脚本后，必须 `Unity_GetConsoleLogs Type=Error` 确认 errorCount==0**。否则程序集编译失败时，Unity 退回旧程序集、MCP 重生成会静默跑旧码（`isCompilationSuccessful=true` 会骗人），改动看着"没生效"。本会话被 `treesPlacedHere` 漏声明坑过。
- MCP 桥"Connection revoked"＝双 relay 卡座：`pkill -9 -f "relay_mac_arm64 --mcp"` + `pkill -9 -f "RelayApp~/relay"`，再 ping 一次。
- 重启编辑器后用 `open "Unity.app"` 可能只开 Hub/选择器、不进工程；要进工程用 `"<Unity.app>/Contents/MacOS/Unity" -projectPath "<工程>" &`。
