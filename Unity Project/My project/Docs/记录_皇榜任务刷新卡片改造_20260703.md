# 皇榜任务刷新卡片改造记录（2026-07-03）

## 结论

本轮确认并修正了需求边界：**不要在地图世界层额外挂皇榜任务标记**。皇榜任务刷新只在右侧 HUD 事件卡中表现。

最终视觉结构：

- 整张右侧 HUD 事件卡切换为“皇榜公告牌”主体。
- 任务刷新时隐藏普通事件卡半透明黑底，公告牌直接作为背景主体。
- 公告牌中部：较小事件图。
- 公告牌下部：任务地点/公开状态、任务名 + 加分，文字必须落在榜文纸面内，不压到底座/牌脚。
- 公告牌整体略向右贴近屏幕边界；右移时公告牌、插图、地点行、任务/加分行必须整体同步移动。
- 插图和两行文字之间必须留出明确垂直间隔，不能让地点行或任务/加分行压到上方图片。
- 右上角纵向栈必须保持：小地图 -> 小分队事件提示条 -> 皇榜公告牌。三者静态和滑入动画期间都不能互相遮挡，皇榜公告牌也不能压到底部 HUD 上方事件条。
- 主文案：任务名 + 加分，例如 `抵驿催运任务  +30分`
- 副文案：地点/公开状态，例如 `南岭驿 · 位置已公开`

## 防回归约束

1. 不要把任务刷新重新做成地图世界标记。
   - 地图上站名、小队、进度条、资源/障碍标记已经很密，任务刷新再加世界皇榜会遮挡。

2. 不要把皇榜任务刷新卡的专用布局套给所有事件卡。
   - 战斗、资源、完成、核验等事件仍然走通用事件卡布局。

3. 不要把底部任务/分数区域退回纯色黄色块。
   - 任务刷新事件卡本身就是公告牌，黄色结果条在该布局中必须隐藏。

4. 不要给任务刷新公告牌再加普通事件卡半透明黑底。
   - 公告牌图已经承担背景和容器职责，再加黑底会显得粗糙、遮地图。

5. 不要把任务名/加分放到公告牌底座外。
   - 任务文字必须在榜文纸面区域内完成排版，宁可收小字号，不要压到牌脚。
   - 同时也不能向上压到事件图；地点行和任务/加分行要与插图保持清晰分隔。

6. 不要把 `world_marker_imperial_notice_board.png` 重新挂回地图世界层。
   - 该图在这里是 HUD 事件卡主体，不是地图任务标记。

7. WebGL 验收必须跑 HTTP 包。
   - 不能只看 Unity Editor 或 `file://`。

8. 不要把右列三段重新调成互相覆盖。
   - 小分队条上边要贴小地图下边，但滑入动画也不能插进小地图。
   - 皇榜公告牌上边要贴小分队条下边，但不能盖住小分队条。
   - 皇榜公告牌底部不能压到底部 HUD 上方事件条。
