# 交接：事件特效改 3D 模型（冰鉴/快马/荔枝转坏）— 设计已与用户对齐 2026-06-29

## 背景
用户反馈现在头顶的 2D 图标贴图「冰鉴像个盒子，分不清」，要改成**三个 3D 模型**大大悬在车队头顶；并问脚下贴地花纹要不要也做 3D。已设计并对齐（4 个决策见下）。**镜头约束不许动**（之前给这三个事件加的 `SetEventFocus` 已撤）。当前实现见 `LycheeConvoyVfx.cs` 的 `EventIconRoutine`（2D 图标+暗底盘+配色光环+文字牌）、`PlayEventPillar`（配色竖直光柱）、`GroundDecalRoutine`（贴地平花纹）。

## 用户已拍板的 4 个决策
1. **造型**：按推荐剪影——冰鉴=向上张开的**冰棱/冰晶簇（绝不是盒子）**；马=**奔马侧影**；荔枝转坏=**发蔫裂开的荔枝串**。三者「尖／长／圆」，没看清颜色先靠形状分。
2. **脚下**：**砍掉贴地平花纹**（`GroundDecalRoutine`），换成**悬空发光圆环**——浮在队色圈(y0.05)上方约 y0.5、比队色圈大一圈(外径~2.0-2.4)、**有厚度的细环**（torus，不是零厚度平片，否则斜视角看不见）、随距离放大、URP/Unlit 自发光配色、暖色往白提亮 30-40%。零包体增量，不挡队色、不穿河道山脊。
3. **快马/短驿马共用一个马模型**，只用 tint + 光柱高矮 + 缩放区分。
4. **文字牌不要了**（用户 2026-06-29 二次修正）：3D 模型已经够清楚看出是啥，文字图片叠在一块图层太多。同时**暗底盘也去掉**（衬在 3D 模型后面像贴纸）。**只留**：3D 模型 + 一圈柔和配色光环(颜色提示+从乱战场里托起) + 光柱 + 脚下悬空发光圆环。光柱保留：冰/荔枝转坏收细、快马留作速度光束。
5. **头顶模型「永不被挡」**（用户 2026-06-29）：模型悬在车队中心上方的空处，且**渲染成 always-on-top**（盖过场景几何，不被车厢/其它车队/地形挡住），像个始终亮着的信标标住这支车队。实现可用 ZTest Always / 专门的 overlay 渲染（实现时定），注意保持模型自身 3D 体积观感（别因关深度测试导致自穿透）。

## 模型规格（用户照此制作）
- **格式**：`.glb`（贴图内嵌），一个事件一个文件。
- **放置 + 命名**：`Assets/LycheeReplayDemo/ModelsGLB/` → `event_icebox.glb`、`event_horse.glb`、`event_spoil.glb`。建好在模型清单 .md 里登记。
- **面数**：目标每个 ≤1500 三角面（硬上限 ~3000）。**你不用纠结导出面数**——图生模型常是几万面的高模，直接交给我，**放进来时我负责减面**到预算（见接入第 0 步）。能在生模工具里勾"低模/lowpoly"更省事，但不强求。
- **贴图**：最好无贴图（顶点/材质纯色最省）；要贴就一张 ≤256–512px 基础色内嵌、无法线/金属/粗糙度（运行时强制改 Unlit/自发光，PBR 白费）。每个 ≤~300KB。
- **材质槽**：1 个最好，最多 2。别用 Standard/PBR。
- **轴心**：几何中心（自转才原地转）。
- **轴/单位**：Y-up、+Z 朝前、米单位、约 1–2m、导出前缩放冻结成 1（运行时按屏幕目标大小归一化）。
- **不绑骨骼/动画**：浮动+自转代码加。
- 可复用省事：荔枝串可由现有 `lychee_crate_open.glb` 派生、马可由 `Horse.glb`/`horse_new.glb` 派生；冰棱簇是唯一全新但最简单（几根挤出的棱锥）。

## 模型到位后我要做的接入（待用户交付 GLB）
0. **减面（必做，用户交付的多半是图生高模）**：每个 GLB 先查三角面数，超预算就 decimate 到 ≤1500（硬顶 3000）。首选 `gltf-transform`（npm，meshoptimizer 内核）：`npx @gltf-transform/cli simplify in.glb out.glb --ratio <自动> --error 0.01`，再 `weld`/`dedup`/`prune` 清理；它保 UV、改善的同时保剪影。装不了/效果差就退 Blender headless 的 Decimate(Collapse) 修改器。减完复核：剪影没塌、轴心仍在几何中心、Y上+Z前、材质槽 ≤2、贴图 ≤512px。减面后的文件才放进 ModelsGLB/。
1. `LycheeReplayPlayer.cs`：加 3 个 `public GameObject` 字段(eventModelIceBox/eventModelHorse/eventModelSpoil) + `GetEventModel(string resourceType)`；Inspector 里指认 prefab。加 `CreateNormalizedOverheadModel`（仿 `CreateNormalizedModel` 的 bounds 归一化，但按 `bounds.center` 坐到 ~y2.9 而非 min.y=0）。
2. `LycheeConvoyVfx.EventIconRoutine`：**层级拆分**——只有那圈柔和配色光环留在 billboard 子根（保持朝相机+恒定屏幕大小）；**文字牌(EventIconCap/Shadow)和暗底盘(EventIconDisc)删掉**；**模型放单独的非-billboard 子根**（保持自身朝向，否则被压成平片=最大的坑）。分支：`player.GetEventModel(...)!=null` 就实例化模型、跳过 2D 图标块；否则回退现有 2D 图标。
3. 模型行为：坐 ~y2.9、反距离缩放 `Clamp(camDist/22,1,2.4)`（同光柱/徽记）、上下浮动 + 慢自转(~40°/s)；**进场遍历所有子 Renderer 强制 URP/Unlit 或 URP/Lit+自发光 + 事件 tint**（导入 GLB 材质在 WebGL 构建会变洋红，必须强改）；shadowCastingMode=Off、receiveShadows=false。**always-on-top**：材质 `_ZTest=Always` + 拉高 renderQueue（或专门 overlay 渲染），让模型盖过场景几何永不被挡（决策 5）；留意别让关深度造成模型自穿透——必要时模型用独立 overlay 相机/RenderObjects 清深度再画。
4. 脚下：移除三事件的 `GroundDecalRoutine` 调用，加「悬空发光圆环」协程（把 `CreateRingMesh` 挤成有厚度细环）。
5. 清理：`EventIconRoutine` 收尾块 Destroy 模型实例 + 其运行时材质 + 圆环，防长回放泄漏。
6. 验证：HTTP 服务的 WebGL 构建里确认不洋红、远近可读、圆环不 z-fight、多车队同时触发时透明 overdraw 可接受。

## 验证踩坑备忘（见 memory event-vfx-fires-but-too-subtle）
- 车队 rig 只在**真正播放**时建；新 play 会话要先 `SetPlaying(true)` 放几秒再 seek，否则 `GetConvoyRoot/FindRig`=null、特效不生成。
- 截图用 `RenderPipeline.SubmitRenderRequest`(URP 同步渲染)+System.IO 写 PNG；MCP Camera_Capture 在本工程失败。
- GameObject 没 `.position`，要 `.transform.position`（手滑会编译失败→进不去 play→连锁假象）。
