# 道路材质详细设计（每类路：素材包/贴图/shader/生成）

> 原则：**优先复用已有素材包、用精细 PBR 贴图、避开粗糙纯色、全图风格统一**。
> 好消息：四类路面 + 河床 + 地形 + 水的**精细材质大多已经存在**（建立在 ALP 真实风 PBR 上），核心只差"按类型把它们赋上去"——现在主路面/水面**根本没按类型赋材质**（克隆模板继承），这是要修的洞。

---

## 0. 风格裁决：全图统一走 **ALP 真实风（4096² PBR）**

工程里有三套候选，结论是**只用 ALP，弃另外两套**：

| 素材包 | 质量 | 裁决 |
|---|---|---|
| **ALP Realistic Terrain Textures Lite** | 4096² PBR，含 法线/高度/AO/高光/mask 全通道 | ✅ **主选**——地形/河床/官道/山路现状已全建在它之上，最精细 |
| Pure Poly 低多边 | 1024² 卡通手绘风 | ⚠ 风格与 ALP 撕裂，**不混用**（河床那张卵石是它的，已用、保留即可，不再扩） |
| LycheeSandbox/Materials（OfficialRoad/MountainRoad/Cliff/Stone…）| **全纯色、零贴图** | ❌ 正是你要避开的"粗糙"，弃；只可借其 _BaseColor 数值当配色参考 |
| Hill Rock Mountain / FreeMountain | 2048² PBR，但是**模型 UV 图、不可平铺** | 只能做 3D 岩块/崖体 prop，**不能铺到路带上**（会糊） |

**四类一眼区别公式**：官道=**亮褐夯土·平** ／ 支路=**暗褐素土·穿草地** ／ 山路=**灰裂石·凸起** ／ 河道=**黄绿动水·下挖**。
→ 颜色（褐/暗褐/灰/绿黄水）+ 地势（平/随地/凸/凹）**双重区分**，不再靠抽象彩带。

> 支路的"草"哪来：支路是窄土带，**周围地形本就是 Ground005 绿草**，土路穿草地而过自然得到"土+草"观感；想更明显可把支路路基收窄、多露草。

## 3. 怎么生成（落点，全部在 `LycheeMapLayoutGenerator_20260613.cs`）

**① 主路面材质洞（核心）**：`ReplaceRibbon()`（L800-810）重画 `E##_Route` 时**只设 MeshFilter.sharedMesh、从不设 MeshRenderer.sharedMaterial** → 四类路面全继承克隆模板、不分。
修：仿照已有的 `FindRoadbedMaterial(type)`（L764，路基已经分型了）新增 `FindRouteSurfaceMaterial(type)` 返回上表四个 `M_Config_*` 主路面材质；在 `_Route` 重画后 `mr.sharedMaterial = FindRouteSurfaceMaterial(type); EditorUtility.SetDirty(mr)`。Water 跳过（水面归 ②）。

**② 水面材质洞（同病）**：`ReplaceCarvedWater()`（L1437）也只设 mesh 不设材质；且 `FindWaterMaterial()`（L1867）的 preferred 列表**恒命中第一项 `M_RiverWater_Fuller`，IgniteCoders 水永远轮不到**。
修：(a) 新建 `M_RiverWater_IgniteMuddy.mat` 放进 preferred 列表**首位**；(b) 在 `ReplaceCarvedWater` 给水面子物体的 MeshRenderer 赋 `FindWaterMaterial()` 返回值。交汇水舌 `CreateWaterJunctionObject`（L1544）已用同函数 → 自动统一。

**③ 支路换贴图（唯一的材质资产改动）**：把 `M_Config_BranchRoute.mat` 的 `_BaseMap/_MainTex/_BumpMap` GUID 从 `Ground003`(dd4cb115) 改为 `Ground001`(e6b40e30)，`_BaseColor` 压到 ~1.05/0.92/0.72、`m_Scale` 收到 0.30。**改 .mat 文件即可，不动代码**。（Ground001 是 RGBA，记得在其 .meta 关 `alphaIsTransparency`，否则路面发灰透明。）

**④ 新建一个 .mat：`M_RiverWater_IgniteMuddy`**（克隆 IgniteCoders `Water_mat_01` 改成"泥沙河浑浊缓流浅水"，shader 仍指 WaterShader.shadergraph）：
- Deep Color → 暗黄绿 `(0.20,0.26,0.16,0.90)`；Shallow → 浅黄绿 `(0.42,0.46,0.28,0.30)`
- Depth `-3.5→-1.3`（浅，看得见沙底）；Normal Tiling `10×10→4×4`（缓流大涟漪）
- Strenght `0.2→0.08`、Displacement `0.1→0.05`、Distortion `1→0.4`（缓流，无独立流速属性靠这几个一起调慢）
- Smoothness `1→0.55`（浑水不镜面）；Use Reflection **保持 0**（俯视回放不需要 WaterReflection.cs，省一台相机+RT）
- **不要改原包 Water_mat_01**，克隆出来改，保留素材包原样。

**⑤ 崖（另算）**：崖体用 Hill Rock `rock_set_mat`（2048² PBR 岩块）做 3D prop 摆放，不走路面 ribbon 管线。

## 4. 关键安全性

- **动态水零顶点位移**（已查证 ShaderGraph 顶点块无输入边）：动画纯 UV/法线流动 → **不破坏小队"划船/走路"判定的水面三角缓存**。这正是之前担心的点，IgniteCoders 这套天然安全。
- tiling 全在各 `.mat` 的 `m_Scale`，赋 `sharedMaterial` 即自动带上，生成器侧不用再设 UV。若多段路要避免共享材质被改，用 `MaterialPropertyBlock` 设 `_BaseMap_ST` 而非改共享资产。
